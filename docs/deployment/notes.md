# F101：Apple 备忘录接入验证

仅验证合成笔记，不是正式 OKR 讨论功能。使用 macOS 自带 Notes 脚本接口（JXA / osascript），Node.js 24，无新增依赖。接口依据本机 `/System/Applications/Notes.app/Contents/Resources/Notes.sdef`。

## 运行

先确认目标账户/文件夹存在且已获用户授权。本次用户授权 `iCloud / Notes`，创建、更新、读回一篇合成测试笔记并保留。

```bash
npm run test:notes
npm run verify:notes -- --write-synthetic --account iCloud --folder Notes
```

首次访问可能弹出 macOS 自动化权限请求，允许运行宿主控制“备忘录”。在系统设置 → 隐私与安全性 → 自动化查看授权；当前宿主成功不表示其他宿主或 OpenClaw 已获授权。缺失 `--write-synthetic` 时在访问 Apple 前停止。

命令首次按唯一账户名/文件夹名绑定真实 ID；同名多个或不存在时停止，不创建文件夹。创建带 `PGTD F101 合成测试` 前缀和随机标识的笔记，保存初始记录，再追加一条更新。结果包含真实 ID、调用数和耗时，不输出正文。

同一命令再次运行只读回原笔记，不重复创建或追加。状态保存在 Git 忽略的 `runtime/notes/probe.sqlite`，包含真实 ID、操作意图和写前快照，文件权限 0600，新目录 0700。仅支持本机单进程；PID 复用会保守拒绝打开。不要删除状态或换 `--state-path` 重试，否则会成为新的验证、创建另一篇笔记。

## 停止与恢复

- 创建响应丢失：再次运行在已绑定文件夹以随机标题缩小候选，再核对正文标识；唯一匹配才复用真实 ID。不存在或多个匹配均停止，不将“查无结果”视为“从未写入”。
- 追加响应丢失：再次运行只按笔记 ID 读取更新标识；未找到则停止，不重复写入。
- `CONFLICT`：写前 HTML 与读取快照不同，拒绝覆盖。后续运行若找不到追加标识会报告 `UPDATE_RESULT_UNKNOWN`；须人工核对，不清空状态重试。
- `LOCATION_NOT_UNIQUE`：位置不唯一、不可用，或笔记已移动/删除；`BINDING_CHANGED`：同一运行状态传入不同位置。
- `PERMISSION_DENIED`、`APPLE_TIMEOUT`、`APPLE_RESULT_UNKNOWN`：检查权限与 Notes 状态，再使用原状态核对。系统错误若无法精确识别会保守报告结果未知。
- `UNSUPPORTED_NOTE` / `UNSUPPORTED_FOLDER`：拒绝锁定、共享、带附件笔记或共享文件夹。
- `CAPACITY_EXCEEDED`：文件夹超过 1000 条或笔记 HTML 超过 32768 个 UTF-16 单元；恢复最多读取 10 个同标题候选，超限停止。最初 200 条上限在真实文件夹的 376 条元数据计数上触发，随后据此调整预算。

每次验证最多 8 次 Apple 调用，单次 15 秒超时，脚本输出最多 256 KiB；写入不自动重试。超时终止脚本进程不能撤销已交给 Notes 的请求。模型调用 0、模型费用 0。脚本正文可能经 Notes 规范化，不以写入 HTML 与返回 HTML 字符完全相同作为成功条件。

## 2026-09-27 验收证据

- 首次创建、追加及同一真实 ID 读回成功：5 次 Apple 调用，4225 ms。
- 独立新 Node 进程复用成功：2 次只读调用，1544 ms；没有第二条笔记或第二次追加。
- 在授权笔记上按标题加随机标识查询，恰好一个匹配且 ID 一致。
- 向真实追加接口提供过期快照，返回 `CONFLICT`；随后读取确认正文未变化，合成追加记录仍只有一条。
- 真实 ID 与补充验证结果仅保存在私有 `runtime/notes/verification.json`；合成笔记保留，未删除。
- 自动化测试：10 个 F101 行为测试；全套 88/88 通过。语法检查、模拟飞书示例及插件离线验证通过。

上述耗时为单样本，不是容量基准或延迟承诺。首次运行之后提高了容量保护上限，未再次创建笔记。

## 已知限制与 F103 输入

Notes 没有原子比较并交换或服务端幂等键。快照核对能拒绝已发生的编辑，但无法消除核对后、写入前的竞争或 iCloud 延迟同步覆盖；本次未进行真实多设备冲突注入。未撤销系统权限来实测拒绝分支，拒绝权限与响应丢失通过模拟故障验证；真实成功授权、ID 续接和过期快照拒绝已验证。

本次只有合成短文本，未验证富文本、附件、长历史保真或跨设备 ID 长期稳定性。更换状态目录/独立部署没有跨实例去重保证；恢复候选被改名后会保守停止。不得直接将此验证工具接入正式 OKR 写入。F103 仍需冻结讨论关联、正式笔记绑定、历史保存、并发编辑策略与生产恢复预算。F102 原生提醒事项标签验证尚未开始。
