# 逐项 OKR 讨论验收（2026-09-28）

## 使用方式

飞书发送“小婕 gtd okr 讨论”，回复对应回执逐轮继续。先明确年度/季度和起止日期，再一个 O 下逐个讨论 3–5 个 KR，每轮一个核心问题与建议；未形成完整数量时保持工作草案。工作草案随检查点保存，暂停、重启后续接。

沿用 grilling 的决策树质询；按用户“一个一个讨论”要求，每轮只推进一个决定。追问目标价值、证据、机会成本、失败假设和替代策略。O 描述期望变化，KR 描述可验证结果，基线未知时写未知；衡量方式与策略质量仍需用户和模型判断。

周期/O/KR 使用三级标题；备忘录格式为“标题／小标题／副标题”。正文保留 Markdown 层级标记和原生目标标签。反向审视后展示完整草案，明确确认才覆盖最新稿，旧版先归档日志。
