# GTD 架构与数据草案

飞书 → OpenClaw 路由 → GTD 领域流程 → Apple Operations 工具 → 提醒事项 / 日历。

## 职责

领域流程负责澄清、组织、规划和 Review；Skills 描述流程；工具负责可验证的读写、权限检查、幂等及审计。独立 Agent 的运行形式待确认。

## 工具建议

- reminders：list / get / search / create / update / move / complete。
- calendar：list / query / free_busy；写入能力按确认策略开放。
- 项目档案：经共享接口创建及关联 Obsidian 项目，避免与 Wiki 并发覆盖。

Apple 接入优先评估 EventKit 或稳定 CLI；需验证目标账户、数据可见性和权限。

## 关联字段

提醒事项备注建议保存 project_id、source_id、origin、created_by。保存工具返回的 reminder_id / calendar_id；不得用标题充当唯一标识。

项目档案建议包含 project_id、title、status、area、success_criteria、reminder_ids、calendar_ids、source_ids、next_review_at。任务摘要从 Apple 派生。

## 建议 Skills

capture、clarify、create-project、plan-day、waiting-review、daily/weekly/monthly/quarterly-review、calendar-query、mail-metadata-scan。

## 实施顺序建议

1. 确认列表、标签、项目表示法及候选入箱策略。
2. 在测试数据上验证 Apple 读写和重复请求。
3. 飞书任务收集与项目关联。
4. 早晚简报与周回顾，再扩展月/季度 Review。
5. 接入 Wiki 候选，验证失败恢复；邮件随后接入。
