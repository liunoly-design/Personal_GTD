# Domain docs

本仓库采用单领域布局。按当前任务读取：

1. 根目录 `CONTEXT.md`：统一业务术语。
2. `需求文档.md`、`待确认问题.md`：已确认边界及未定事项。
3. 当前规格和任务；需要架构背景时再读 `架构与数据.md`。
4. `docs/adr/` 中与改动有关的决定；尚无 ADR 时直接继续，不预建空文档。
5. 涉及 Wiki 协作时读 `docs/context/跨项目协议快照.md`。

保留原始问答，用户最新明确决定优先。重大且难逆转的工程取舍才按需写 ADR，小决定写入当前规格。
本地存在 Personal OS 上级目录时，跨项目变更回写其设计决策及协议，再更新本仓库快照；独立克隆时记录待同步事项，不杜撰上级文件内容。
