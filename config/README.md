# 配置示例

此目录只保存合成示例，真实配置复制到 Git 忽略的 `runtime/` 后填写。

- `config.json`：模拟收集的身份、激活词、时区与超时。
- `model-config.json`：模型运行与预算示例；运行会产生实际费用。
- `openclaw-plugin-config.json`：插件启用、授权范围与私有文件路径。
- `feishu-runtime-config.json`：Apple 与模型运行配置。

安装步骤与授权边界见 [部署说明](../docs/deployment/openclaw-handoff.md)。保留已有费用账本和状态目录；示例预算数值不构成授权。
