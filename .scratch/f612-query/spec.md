# F612/T01 注册状态与心得原文查询

基准70a2bbd，2026-10-07。仅已有DOPL注册，不新增注册管理或摘要模型。
公开已约定测试接口：可信飞书openFeishuCapture.handle → 回执及Notes外部可观察读写；只替换外部服务/时钟。
命令：小婕 review 查询注册/注册状态；查询今天心得/查询昨天心得/查询 YYYY-MM-DD 心得；查询近期心得 [第N页]。近期含消息当天及前6天，按心得日期逆序，同日独立记录保留笔记顺序。明确日期可分页。
输出：注册配置/状态与心得结果不同对象；原文、心得日期、真实记录时间（旧格式明确无时间）、真实笔记ID、范围/页/总条数/下一页。每页最多3条且原文总计4500 Unicode字；单条超过预算拒绝而不静默改写；单年读取65536纯文/131072HTML，每次最多两个已绑定年度，桥接沿用8次/120秒预算，0模型、0Notes写。最多1000事件，不扫账户/全历史；页码1..1000，无界扫描拒绝。
兼容MMDD-心得的当前正文与PGTD-DOPL-RECORD时间块；剔除恢复标记与历史修订正文；无可信边界或重复旧条目报歧义，不猜测。查询不影响现有问答/pending，不进入Inbox；未注册、年度未绑定、无数据、歧义、权限拒绝及服务失败不同回执。
验收：零Notes写/模型；多条同日、跨年、分页、旧历史、空/失败/权限/重复/重启/可信用户会话；完整回归和真实授权Notes只读查询。性能合成实测，真实延迟待测。
