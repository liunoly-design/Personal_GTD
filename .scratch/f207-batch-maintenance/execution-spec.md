# F207/T01 多任务确认完成与移动

基准2c1bf67，2026-10-03。用户明确要求开发多任务确认完成及移动，本交付包含其F110/T01移动接入依赖；不开放删除、重开、跨账户或创建目标清单。

输入：回复可信任务查询回执“第一第二项完成，第五项移动到Next清单”；最多10项。输出具体任务名称、动作、目标清单；批量先零写入生成计划。回复该计划“确认执行”后逐项完成/移动并读回；“取消”无写入。单项完成保留直接执行；单项移动同样先计划确认。

确认绑定原用户/会话、原查询快照、计划ID及唯一版本；同原查询新计划替代旧未执行计划。不是回复计划的确认、旧计划、跨身份均不执行。先验证全部源任务与目标清单唯一性、源/目标可写性；缺失/歧义/冲突阻塞整个计划。计划执行不是Apple事务，预检通过后独立项失败逐项报告，允许其他独立项继续。

真实ID原地移动，保留原任务对象及完成状态、标题/备注/URL/时间/提醒/优先级等可接入字段；带复发规则或位置提醒的移动暂时阻塞；禁止复制替代。移动读回使用不含列表/ID的内容指纹，与原任务ID/目标/状态共同核对；ID发生变化或隐藏字段不能核实报告未知，禁止重写。默认收集绑定不变。

每项写入意图先持久化，成功或明确拒绝记录终态，写入结果未知只核对；重投/重启不重放已开始项。确认后的未开始独立项可恢复，撤回用户/会话授权则停止。未决完成/移动保护同真实对象，换消息不能绕过。回复结果不继承查询编号。

沿用已确认公开测试接口openFeishuCapture.handle/recover、Apple adapter与Swift JSON bridge。TDD：两完成一移动、零确认写入、取消/替代/越权、字段与ID/默认绑定、失败/未知/部分成功/重启/确认重投及回执未知。真实写入仅限单独授权的合成源/目标/任务；模拟通过不等于真实验收。

预算：10项、提案每项一次读取、每个不同源/目标至多一次解析；确认全计划再预检一次，执行每项预读/写入/读回各最多1次，写前再检查目标可写性，每调用<=20秒，每个提案/执行事件总预算180秒。恢复每个已开始项最多一次核对；单次至多恢复一个10项计划。输入8000字符、现有16队列/1000事件限制不变。无模型调用。真实性能/原地ID稳定性待测，模拟五项三动作记录延迟。
