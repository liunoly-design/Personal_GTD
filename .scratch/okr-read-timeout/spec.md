# OKR 日志读取超时修复

基准：eafb61b1db0bcea0af14f52f4985e985ce403a1c（开始时已有其他未提交工作）。

用户目标：飞书 OKR 讨论在已有较长日志上能够继续。
范围：Notes 桥接预算与只读快照；不重写历史、不清除去重状态、不改变模型预算。
输入输出：原 Notes bridge 请求，返回相同的笔记快照或明确错误。
失败处理：单次总预算 60 秒，可显式缩短；未知写入仍核对后恢复，不自动重试。
测试接口：createNotesBridge 的外部脚本/编辑器边界，现有 OKR handle 测试。
验收：预算回归先红后绿；真实原笔记只读成功且标题/标签完整；受影响套件及语法检查；网关重载。
性能：本机当前日志约 1.24 万字符；修复前完整读取 25.5 秒，修复后一次读取 14.6 秒。单样本，不保证固定提速比例。
限制：飞书新消息端到端续接仍待用户验收。
