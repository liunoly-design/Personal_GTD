# OKR 备忘录故障定位

基准：a3d3b111c0a7396712b53a9187781ed05fb75bfd。

目标：用户在持续 OKR 讨论中收到记录未确认完成时，能区分超时、界面占用和权限故障，并定位失败的 Apple 操作。

范围：错误码白名单、操作阶段、脱敏本地诊断和插件日志；不增加模型预算，不自动重放未知写入。
输入输出：现有飞书可信消息接口；错误结果包含 code 与 operation，回执对超时和界面占用给明确解释。
失败处理：未知异常仍映射 NOTES_UNAVAILABLE，原始异常正文不写日志。保留既有 pending 核对和幂等行为。
测试接口：既有 openFeishuCapture.handle 与插件 reply_dispatch；合成 Apple 边界错误。
预算：每次错误一条本地诊断（沿用事件数量上限），无模型调用、无新增重试。真实读取延迟待测。
验收：读取超时不丢错误码和操作阶段；完整检查通过；真实卡顿原因和原回答恢复单独记录，不以模拟测试替代。

## 读取冲突修复

真实测试取得 CONFLICT/read。对编辑器只读核对冲突，在原 15 秒截止时间内最多再取得一次脚本快照并核对；追加、替换等修改操作不重试。持续冲突仍停止。新增公共桥接接口测试验证短暂冲突恢复、持续冲突次数上限和写入不重试；不能将短暂切换假设表述为已确认根因。
