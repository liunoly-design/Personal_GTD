# OKR 逐项质询、周期与标题层级

基准6905c08。用户要求 grilling skill 模式、OKR 方法论、一次一个 O 后逐个3–5个 KR、标题层级和时间段。

当前单任务：改进既有讨论入口与定稿结构，不新增笔记、Review调度或标签映射。周期先明确年度/季度名称及 YYYY-MM-DD 起止日期；O 描述有价值的变化，KR提供基线、目标值、证据与检查日期；未知事实保留待确认。grilling 围绕当前决定追问依据、机会成本、反例和替代策略，每轮一个核心问题，等待用户后续回答。

公开测试接口：validateGuidance、openOkrSession.handle、openFeishuCapture.handle、真实 callNotes。模型草案使用一级周期标题、二级 #O 标签标题、三级 #KR 标签标题。阶段okr允许不完整草案；challenge/ready要求每O有3–5KR，周期合法，标签唯一且KR归属明确。比较前后草案，每轮最多新增或改变一个O/KR；新O不能跳过前O的3个KR。会话持久化工作草案并传回模型，重启续接；旧目标全文作为背景，不隐式确认新目标。

预算不扩张：每条回答最多一次模型调用，现有45次/0.5美元；本轮先做模拟和已授权合成笔记格式验证。真实模型多轮质量依赖额外授权。Native Notes 标题样式通过现有辅助功能桥接执行，保留可读层级标识与原生目标标签。保存失败不推进，现有恢复/定稿确认保持。
