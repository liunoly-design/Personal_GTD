# 按动作拆分与 SSH 同步

基准：92f3ee8。用户要求配置 SSH、保留多种推送方式，并让每个 GTD 动作可分别升级。
范围：提取现有收集、设置提醒、补时间和链接确认行为；统一入口、权限与日志保持原有接口；SSH 443 专用别名、公钥登记、普通推送全部提交，HTTPS 备用远端保留。
输入输出：既有 handle(event)、checkpoint 与外部适配器接口不变；动作模块独立文件和局部测试命令。
失败处理：原有分析降级、写入未知停止、去重、回复关联、恢复和取消均保持。SSH 认证失败保留本地提交，不强推。
测试：现有公开行为测试和每动作命令、恢复/飞书模拟、隔离插件加载；真实账号验证与远端 SHA 核对。
预算：无新增依赖、模型调用或外部业务写入；分析调用次数与性能预算不变。不是多服务独立部署，单功能更新仍需重载网关。
