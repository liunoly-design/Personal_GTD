# F108/T04：指定列表只读查询

Feature: F108/T04

用户要求“我想查我特定列表任务…要加上”。本项只扩展列表范围，不实现关键词/日期筛选或全部列表遍历。

## 范围与接口

可信同义查询动词沿用现有规则，新增完整表达“查询工作列表的任务”“查询列表 工作 的任务”“查询「工作」里的任务”，可附“第 N 页”。列表名称可用「…」/“…”/ASCII双引号包裹；仅按完整名称解析，英文大小写忽略，不按子串选中。名称1..200字符，禁止控制字符/换行。带引号支持含空格、标点及“列表/的”字样的名称。不带引号的“所有/全部”保持能力提示，不冒充全部列表查询。

默认查询仍使用原绑定列表；显式查询只在配置sourceId所属账户里选择目标。一次查询先解析真实列表ID，再只读这一列表，返回原scope/items结构与人可读回执；不得更新binding、创建列表或事项、模型调用、规划/复盘。native queryTasks输入增加可选listName，显式输入不使用默认listId；原按ID默认读取不变。公开seams沿用openFeishuCapture.handle/recover、Apple adapter/queryTasks与外部Swift JSON桥接。

未找到返回query_list_not_found，说明已配置账户内没有该列表，不fallback到Inbox。同名多个返回query_needs_list及结构候选ID，回执提示在提醒事项中区分名称后重查；本项不假装已经支持编号选择。无默认绑定也可显式读取唯一命名列表，不据此绑定收集位置。无权限/失败/空列表/超时保持原分类。跨账户、ID手输、日期/标签/关键词筛选/复合操作另行切片。

页码1..100，每页默认20（1..50），单次15秒（可配<=20秒），全列表源对象最多10000。查询下一页命令必须携带本次列表名，用引号规避名称歧义；旧事件仍复用首次快照，新事件重新解析真实对象。外部列表并发改名/删除可能导致新页不存在，不能回退默认。真实性能/大列表内存待测，无新依赖。
