# F108/T08 自然编号与澄清回复规格

日期2026-10-03，基准28f5673。用户目标：回复查询用自然编号表达，不反复试固定格式。

范围：中文编号一至九十九、两及一百；阿拉伯编号；连续“第一第二”“第1第2”、常用分隔、可省略“项”、任务/事项及“标记完成”。只接受完整可确定动作；不调用模型猜测。原编号仍绑定原查询真实ID与字段基线。

输出：单项完成沿用F201/T01；多个完成或移动沿用未实现提示、零部分执行。否定、重复、额外动作、越界按原保护处理。独立发送编号无可信引用仍要求回复查询，不猜最近清单。

仅编号解析失败或维护未上线且具有可信同用户/会话查询关联的提示传递原queryEventId。回复此提示可纠正；持久重启保留，后续新查询不能覆盖原快照。选择结果、完成结果、收集回执及越权提示不传递。旧版错误提示缺新关联可能仍需重新查询。

测试接口沿用已约定openFeishuCapture.handle/recover与公开reminders接口：截图两种说法、中文单项完成、错误提示→更正→单项完成、重启、独立无引用、重复/否定/复合动作、其他用户、原查询越界及完成结果不继承。每次最多10项；输入8000字符，现有事件/超时上限不变。模型0次；未上线批量零写入，单项写入预算沿用F201。性能目标待测，合成演示记录条件及时间。

验收：查询新测试清单后回复“第一项标记完成”，预期完成并读回；两项清单回复“第一第二任务标记完成”预期定位两项并说明批量未上线，无任务变更。真实闭环待用户执行。
