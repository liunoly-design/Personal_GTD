## 用户目标与范围

可信“小婕 gtd 查询任务”及明确同义表达读取已配置 Inbox 的未完成事项（也含文章/想法，收集不代表承诺），展示实际列表、未完成范围、页码、读取时间与真实 source/list/item ID。只读事实，不创建列表或事项、不修改状态、不分析优先级/复盘、不调用模型。

识别完整指令：查询/查看/查一下/看看/看一下/列出/列出来/找一下 + 任务/事项/待办/未完成任务/未完成事项/Inbox，可有“请”“帮我”和“有哪些任务/有哪些待办/任务有哪些”。英文 Inbox 不区分大小写。可追加“第 N 页”，1..100。否定、引用、额外筛选、复合请求不落入查询或默认收集；现有保护返回能力限制/明确单一动作。Q36 复合编排留给共用路由独立任务，本项不部分执行。日历 F401、对象选择对话、维护、已完成/日期/标签/全文筛选、模型路由、全部 Agent 平台不在范围。

## 配置与接口

- 复用 Apple 适配器已持久化的 sourceId/listId 绑定或启动显式 listId；不按标题唯一性擅自绑定，无绑定即询问配置（候选保留真实 ID，同名全部列出）。绑定改名后展示真实名称；不存在/账户不可用报告读取失败，不换列表、不创建 Inbox。
- 公开接口：`openFeishuCapture.handle/recover`（鉴权、回执、重投/重启），`reminders.queryTasks({limit,offset}, {signal,timeoutMs})`（Apple/合成事实读），Apple bridge `queryTasks`。沿用已确认 seams，无需重新采访。
- `queryPageSize` 默认20，1..50；`queryTimeoutMs` 默认15000，1..20000。page<=100，offset=(page-1)*pageSize。选择有限整数页便于明确命令，无 opaque cursor/额外会话。每页重新读取，不保证并发变化时跨页快照一致。
- 按真实 item ID 排序，分页稳定（数据不变时）。查询不限定 PGTD marker，人工创建事项同样返回。最多10000项源数据；超限明确失败，不伪造完整结果。EventKit fetch API 本身一次取回列表数据，之后限量输出；不是原生流式分页，真实容量/内存待测。
- 输出状态：tasks_found、tasks_empty（总数0）、tasks_page_empty（超出当前末页）、query_needs_list、query_forbidden、query_failed。成功含scope、readAt、page、pageSize、total、hasMore、items；标题至多200字符并标明省略，引用 ID 不截断。不返回备注正文。
- 同事件重投复用首次事实快照及读取时间，重启不重读或重发已成功回执；新事件获取最新状态。快照存于已有私有操作状态，不新增权威任务库。发送失败复用原回执恢复，不重查 Apple。

## 失败处理与预算

入口既有身份/白名单/容量/原消息核对不变；未授权入口拒绝读取。Apple权限不足与空结果、普通读取异常分别表达；未知异常只返回固定错误，避免私人正文泄漏。读取超时/取消，无自动重试。外部读取失败不创建事项，不调用模型。候选最多50个，超限只展示前50并明确截断；需要在私有配置选定真实ID后重启，不能用同名自动选择。

单查询最多一次适配器查询；无绑定可能一次列表枚举，绑定一次读取。输出容量为每页50项、每标题200字符、ID各至多1024字符；输入继承既有8000字符和队列/状态1000项上限。token/模型费用0；生产延迟、10000项内存、真实Apple/飞书性能待测，合成演示只记录样本实测。
