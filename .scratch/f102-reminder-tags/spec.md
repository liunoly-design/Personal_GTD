# F102：提醒事项原生标签验证

基准提交：`4cf585194ce63ba8385148a57781c166ea8742f7`。
状态：接口预检完成，真实验证范围确认与快捷指令配置待完成。

## 用户目标

确认原生标签能创建、读取和查询，评估“目标 → 标签 → 提醒事项真实 ID”的关联是否可用于 F109。备注中的井号文本、仅按标题命中、模拟结果都不能算原生标签验收。

## 当前范围与已有决定

- 单个可行性任务；默认单 agent。F101 的备忘录访问已通过，不重复创建正式 OKR。
- 先清点本机 SDK 和系统脚本字典，不访问用户数据；再优先尝试 Apple 官方支持的快捷指令标签动作。
- 拟在 iCloud / Inbox 新建一条带专用标识的合成提醒事项，添加专用测试标签，读回并按标签查询；保留供验收。此新增写入范围已发问，尚待用户确认。
- 不以私有数据库写入、未公开 ReminderKit API 或正文井号替换原生标签；这些未纳入当前实施方案。
- 标签命名、目标粒度及多标签映射的正式业务规则归 F109，本次只验证合成映射。

## 输入输出与测试接口

沿用项目边界：受控合成输入 → 操作结果 + Apple 边界读回。接口预检输入为本机公共 SDK 头文件、系统 sdef 和 shortcuts 命令帮助；输出源文件哈希、声明清单、系统版本及 `liveTagVerification: not_run`。预检成功不等于标签功能成功。

真实路径应接收已授权账户/列表、合成操作标识、标签值及真实事项 ID；返回相同对象 ID、实际原生标签集合、标签查询结果和失败状态。快捷指令具体输入输出格式须在本机编辑器确认后冻结，不能在缺少实际动作字段证据时凭空实现适配器。

## 验收步骤

1. 预检 EventKit 继承链与查询入口、Reminders/Notes sdef、快捷指令 CLI，记录官方来源。
2. 在本机快捷指令编辑器核验标签新增、读取和查找动作；确认列表所属账户及可返回/核对真实 ID 的方式。
3. 创建一条合成事项，获取并保存真实 ID；添加专用原生标签后读回标签，按标签查询确认同一事项。
4. 重复查询/重启后仍能定位同一事项；同名不同行不能被修改。写入结果未知先核对，不能重跑创建。
5. 用合成目标 ID 和 F101 笔记 ID 讨论映射可行性：同名标签建议不证明两个应用共享标签 ID。F102 不发布正式关联协议。
6. 报告权限、ID、标签重命名、跨设备同步及运行依赖限制；真实未测项保持未勾选。

## 失败处理与停止条件

预检资源缺失或进程超时返回失败，不能解释为“不支持标签”。EventKit/sdef 未公开标签不等于所有 Apple 自动化不可用。快捷指令需要安装/配置或授权时保留进度。若原生标签读写/查询或真实 ID 无法可靠核对，保持阻塞并讨论替代设计，不静默降级。用户操作前先完成可审阅的验证清单。

## 预算

预检 3 个只读命令，各最多 10 秒、输出最多 256 KiB；读取 6 个系统资源，每个最多 1 MiB。模型调用 0，Apple 用户数据访问 0。真实验证暂定 1 条合成事项、1 个专用标签、最多 1 次创建及 1 次标签添加；不自动重试。快捷指令单次运行暂定 30 秒，若需首次权限交互则人工在编辑器完成。真实耗时与容量目标待测。
