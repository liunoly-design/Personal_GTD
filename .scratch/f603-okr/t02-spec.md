# F603/T02 单项 SPEC

目标版本0.3.0，未发布。基准为T01独立提交13790ba。

公开边界：可信飞书上下文/规范化模块事件→查询回执与外部文档读回。`小婕 okr 查询当前目标`、`查一下目标`、`查看当前已确认目标`、`看看目标`、`找一下当前目标`、`列出当前目标`、`当前目标是什么`及旧gtd okr前缀；引用/否定/多动作不执行。关联回复可用相同查询表达，不成为回答。仅返回绑定的已确认最新稿，绝不读取当前讨论稿作为目标，不生成草案，不写Notes、不进入Inbox、内容生成模型调用0。

绑定从F104持久latest真实ID和note位置读取；缺绑定询问明确文档，不自动按标题查找、选择或新建。标题可读但定位仅按ID；同名多个不会改变绑定。既有绑定仍须确认稿标记PGTD-FINAL，新发布保存该标记；缺标记/讨论稿、存在未核实publication时不报当前目标。空文档、位置不存在、无权限、读取失败、响应超限分别报告；人工修改当前已确认文档按读取事实呈现，标记缺失停止。

每查询最多一次Notes read，60秒超时/不重试；桥接响应262144字节既有上限，正文最多65536 UTF-16，单页固定2000 Unicode码点（不拆代理对），最多64页。命令“查询当前目标 第2页”或模块page参数，显示页数/范围/来源标题、账户、文件夹、真实ID、读取时间。过大拒绝而非偷偷截断；范围变化后重新查询。页间读取实时快照，独立页面显示读取时间，不声称原子快照。重复同事件返回原回执，新事件读取最新事实。

继承原身份、白名单、来源验证和事件1000限额；本地持久查询回执不等于Notes写入。逐项TDD，空/失败/权限/缺绑定/多候选/分页/重复/原身份/无模型写入/无工作草案冒充，完整合成演示及适用完整检查；实际Notes只读核验在既有授权绑定范围内，不部署或新增业务写入/额度/飞书主动发送。真实模型质量不由确定性查询证明。
