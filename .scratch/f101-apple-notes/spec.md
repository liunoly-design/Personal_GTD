# F101：Apple 备忘录接入验证

基准：`eeb8497c1b15de8b5e1fa2323aaf646a92911a22`。范围仅 F101，一个可独立运行的验证任务。

## 用户目标与范围

验证指定账户/文件夹能创建合成笔记，以真实 ID 读回并追加一条合成更新，为 F103 提供可行性证据。重启后复用原笔记；不读取其他笔记正文，不部署飞书或调用模型。真实账户与位置由用户授权后绑定；不自动创建文件夹。

## 输入输出与实施决定

独立命令显式接收账户、文件夹和真实写入开关；私有运行目录保存真实 ID、操作意图、读取快照与进度。首次名称选择必须唯一，此后使用真实账户/文件夹/笔记 ID。输出只含状态、ID、延迟和验证结果，不输出笔记正文。

仅创建带随机标识的 `PGTD F101 合成测试` 笔记，保留供验收。已有状态必须复用；不得因读取失败重新创建。恢复时标题只用于缩小候选，必须核对正文中的随机操作标识，多个候选停止。更新先比较原始 HTML 快照，不一致报冲突；拒绝锁定、共享或带附件笔记。Notes 没有原子比较并交换，核对和写入间的竞争以及 iCloud 延迟仍是限制，不能作为生产并发安全保证。

## 失败与恢复

写前持久化意图，结果未知先读取核对，无论没查到还是读取失败都不重新创建。追加未知按原笔记 ID 核对更新标识，没查到则停止，不盲目重写。拒绝权限、错误位置、删除/移动、重复候选均停止。运行目录单进程锁；同一状态不允许改变位置。记录固定失败代码，不保存系统错误正文到版本库。

## 测试接口与验收

沿用项目已约定的输入 → 结果 + 外部状态接口：验证函数/CLI 驱动完整路径，Apple 脚本进程为外部边界。逐项 TDD，合成外部替身提供读回状态与故障；真实验证使用系统 Notes 脚本接口。

- 合成笔记创建、追加、读回同一 ID；再次运行和重启不重复。
- 读取失败不创建；创建响应丢失先核对；查无结果停止。
- 人工修改快照冲突不覆盖；追加响应丢失不重复；位置变化拒绝。
- 真实授权后验证指定位置、真实 ID、同一笔记读回及重启复用。
- 系统拒绝权限和多设备 iCloud 并发未实测时明确标注。

## 成本与性能预算

模型调用 0、费用 0；不新增依赖。单次脚本超时 15 秒，输出最多 256 KiB；笔记 HTML 上限 32768 个 UTF-16 单元，目标文件夹最多 1000 条笔记，最多检查 10 个同标题候选，超限停止。每次验证最多 8 次 Apple 调用，不自动重试写入。样本为一篇短合成笔记；真实耗时待测，不承诺延迟目标。无限历史增长和生产 OKR 上下文管理由 F103 规格落实。
