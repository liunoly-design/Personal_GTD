# F614/T01 手动每日心得

基准：6ddbacc2c60c0872a6334e2e628040495b7511c2。仅本任务，不发布整个0.4。

## 用户目标与范围
只启用 Review，通过用户自述完成一个日度心得注册、提问、原文草案、关联确认、Notes读回。固定方法 dopl-original/v1，零模型。年度笔记 YYYY-DOPL，每天一条 MMDD-心得。首版只处理消息发送日期（用户时区），原文不能含独立日期标题或PGTD-DOPL恢复标记（提示改写、不静默变更）；补记、修订、通用查询、调度、其他Review方法不在范围。

## 输入与配置
可信飞书事件沿用当前身份/API/原消息/回复校验。review 配置：account、folder、year（整数1970..9999）、可选noteId、allowCreate（显式true才允许新建）、writeEnabled（显式true才允许注册/保存）、readEnabled（false撤销读取，重启生效）；时区沿用timeZone默认Asia/Shanghai。绑定真实ID，多个同名不猜。没有绑定仅发现年度标题；失败不创建替代笔记。配置中的位置不可静默切换，撤销写权限立即阻止后续写入。

命令：小婕 review 注册 DOPL → 回复“确认注册”；小婕 review 每日心得 / DOPL → 回复问题的非空原文 → 回复当前草案“确认保存”；小婕 review 续接只恢复当前进度/核对未知写入。“取消”终止当前草案。不能裸确认、确认旧草案或其他身份/会话草案。注册是最小单项配置，不建立通用注册库。

## 输出与失败
回执给出日期、方法版本、保存位置、真实note ID与状态。未回答/未确认零心得写入。同日已有条目返回原文和合并/替换待修订提示，T01不写第二条。草案保留Notes快照；人工编辑冲突不覆盖，重新手动发起读取后确认。写前持久化pending；未知结果只读核对原ID及完整投影和标记，未核对成功不重放写入或新建。创建未知按唯一持久marker核对，不自动重建。进程单写者、事件指纹、同日跨会话和撤权保护。

## 已确认测试接口与验收
沿用issue与Review SPEC确认的公开接口：openFeishuCapture.handle/recover、openRuntime和Notes外部读回；只替换外部飞书/Notes与时间，不模拟内部业务。逐项TDD：独立启动；注册/问答/确认保存；旧确认/错身份/撤权；同日重复；重投/重启；写入响应丢失；人工冲突；未知创建/读取失败/多同名；真实Notes专用合成读写（位置和授权需明确）；真实用户飞书闭环分别记录。

## 预算
每条原文最多4000 Unicode字符；单年度正文最多65536字符/131072 HTML字符；每事件最多8次桥接、单次60秒、整体120秒（到期停止新调用），零自动写重试；事件1000条；单次恢复最多一个pending；飞书沿用1000条存储/16队列。生产延迟待测，合成样本至少一个完整流程。Notes现有桥接无跨设备原子锁，保存后必须读回；读取期间人工修改导致无法核对时报告未知。
