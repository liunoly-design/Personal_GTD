## What to build

对已有同日心得明确选择合并或替换，确认后保留一条及修改历史；补记显式指定日期。

## Acceptance criteria

- [x] 先展示已有条目，合并/替换分别形成待确认内容。
- [x] 确认后日期仍一条，旧内容可追溯；未明确合并内容先询问。
- [x] 补记没有明确日期时不猜测，跨年写入正确年度目标。
- [x] 过期草案不覆盖人工编辑，重投与未知响应核对后只完成一次。
- [x] 单项规格、逐项 TDD、完整合成演示、适用检查及顺序审查完成，README 和实际验收记录更新。
