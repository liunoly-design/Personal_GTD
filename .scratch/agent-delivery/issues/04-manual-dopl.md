## What to build

绑定年度笔记、注册一个独立日度心得方法，手动发起后先问用户，展示原文草案，明确关联确认后保存每天一条。

## Acceptance criteria

- [x] 只启用 Review 可通过自述完成注册、问答、确认、YYYY-DOPL/MMDD-心得读回。
- [x] 首路径允许零模型原文记录；未回答不生成最终心得。
- [x] 同日已有条目展示并进入待修订选择，不覆盖或追加第二条；完整修订由 P05 交付。
- [x] 重投、重启、保存响应丢失和人工编辑冲突不重复保存或误覆盖。
- [x] 新笔记创建使用明确目标配置和写入授权，读取失败不新建替代笔记。
- [x] 单项规格、逐项 TDD、完整合成演示、适用检查及顺序审查完成，README 和实际验收记录更新。

## 范围与准备

仅一个日度方法与最小注册，不实现周期调度、专题或 Wiki。

公开测试从模块入口到回执与外部读回状态；使用合成数据，继承批次失败/预算约定。外部授权不因任务发布扩大。
