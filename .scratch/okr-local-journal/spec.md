# OKR 本地讨论日志与 Notes 结果

基准：9744de4。用户确认：日志本地 Markdown，备忘录保存结果及当前讨论稿，确定后讨论稿本地归档。

本任务独立可验收路径：现有日志先本地保留；每轮本地保存原回答与引导，Notes 同一 ID 只保存当前讨论稿；定稿先归档讨论稿和旧结果，再更新正式结果，成功后收起讨论稿。没有明确确认不更新正式结果。

采用 config.okr.journalDir 绝对路径启用。未配置沿用旧版。运行目录受 Git ignore 保护，目录0700、文件0600，默认 journal.md，archive/ 保存历史迁移和每次定稿。文件上限16MiB，当前讨论稿65536 UTF-16单位；模型调用和预算不增加，Notes每次60秒，事件串行。上限容量时延待测。

公共测试接口沿用 openOkrSession.handle 和 Notes bridge；TDD验证多轮笔记不增长、原文本地留存、重投/重启不重复、历史先归档、写入未知先读回、冲突停止。实际迁移先停网关与备份，核对无旧 pending/publication，再迁移；不调用模型、不发送飞书消息。
