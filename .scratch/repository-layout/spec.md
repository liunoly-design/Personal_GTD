# 仓库目录整理与远端同步

用户目标：按需求文档、代码、安装部署、配置分类；推送全部本地提交。
基准：c604af9；开始时 main 比 origin/main 领先 13 个提交。
范围：需求设计文档迁入 docs/requirements，安装文档迁入 docs/deployment，脚本迁入 deploy，配置示例迁入 config。src、openclaw、native、runtime 及工具发现入口保持现有路径。
输入输出：现有受版本控制文件，输出分组目录、修复后的链接与 npm 命令、完整可安装包；保留历史讨论及已有未提交文档修改。
失败处理：验证失败先修复，不推送失败版本；远端前进时先整合，禁止强推；私有文件继续忽略。
测试接口：现有 npm 检查/测试/四组演示、隔离插件验证、Markdown 本地链接检查、npm pack --dry-run。
成本性能：无新增依赖、模型调用或真实 Apple/飞书写入，不改变运行时性能预算。
验收：命令与链接通过，安装包包含新路径且不含私有数据，提交后普通推送 main 并核对远端 SHA。
